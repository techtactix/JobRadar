Spring Based Job Portal

A simple Job Portal REST API built with Spring Boot.

Features
Add job listings
View available jobs
Delete job listings
Basic authentication with Spring Security
Current Status

The project is currently in development.

At this stage:

There is no role-based authentication yet.
All authenticated users currently have the same USER role/status.
User registration has not been implemented yet.
Authentication currently uses a username and password stored in the local database.
Role-based access and user registration will be added in future updates.
Tech Stack
Java
Spring Boot
Spring Security
Spring Data JPA
PostgreSQL
Maven
Future Improvements
User registration
Role-based authorization
